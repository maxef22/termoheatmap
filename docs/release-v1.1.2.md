# Termoheatmap 1.1.2 — заметки к релизу

Тепловая карта температур по помещениям для Automated Logic WebCTRL.

## Файл для установки

`termoheatmap.addon` — ставить **без переименования**: имя файла задаёт контекст аддона
(`/termoheatmap`), страница обращается к сервлетам относительными путями.

Встраивание на страницу оператора: **Add-on Content** → *Add-on Name*: `termoheatmap`,
*Content Path*: `temperature.jsp`, *Location*: Attached.

## Требования

- WebCTRL с **JVM 11** (SDK аддонов `directaccess-api-addon-1.7.0.jar` скомпилирован под Java 11,
  на JVM 8 контекст не развернётся);
- Tomcat 9.

## Что нового по сравнению с 1.1.1

Кратко (подробно — `CHANGELOG.md`):

- в расчёт идут только реальные измерения тренда: служебные метки «связи нет», «неизвестное
  значение», отказ больше не превращаются в температуру 0 °C;
- один часовой пояс на весь аддон (по умолчанию `Europe/Moscow`, переопределяется
  `-Dtermoheatmap.timezone=<зона IANA>`), жёсткий `+3` убран;
- «сегодня» и текущий час считаются на сервере — в 00:00–02:59 МСК больше не подставляется
  вчерашняя дата;
- дерево датчиков по путям локаций: второй датчик в комнате не теряется, одноимённые комнаты
  не сливаются;
- все комнаты читаются порциями по 50 в одном запросе на порцию (было — по запросу на комнату);
- маска по умолчанию — точное имя точки (`zone_temp` больше не ловит `zone_temp_sp`);
- поиск и данные — под правами оператора, а не root;
- цветовая шкала и легенда строятся из одних порогов (убран скачок на 21.0 °C);
- ошибки всегда отдаются валидным JSON; падение одного датчика не ломает карту;
- убраны утечка памяти по `SimpleDateFormat`, лог-спам на каждый сэмпл и передача сырых сэмплов
  в каждом ответе;
- удалён неиспользуемый `TemperatureAggregateServlet`, `debug.jsp` вынесен в `tools/`
  и не входит в поставку.
